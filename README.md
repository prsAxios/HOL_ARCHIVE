# Park Interiors — Interior Design Studio

A premium landing page for **Park Interiors**, a luxury interior design studio founded by Ravi Parmar.

## Features
- **Luxury Aesthetic**: Minimalist white theme with premium typography (Playfair Display & Outfit).
- **Responsive Design**: Fully optimized for mobile and desktop viewing.
- **Dynamic Portfolios**: Showcase projects with smooth animations using Framer Motion.
- **Bespoke Consultation**: Custom inquiry form for new project requests.

## Tech Stack
- **Frontend**: React (Vite), Tailwind CSS, Framer Motion, Three.js
- **Backend**: Hono, tRPC, Drizzle ORM
- **Database**: MySQL

## Setup
1. Clone the repository
2. Install dependencies: `npm install`
3. Configure environment: Create a `.env` file with `DATABASE_URL`
4. Run development server: `npm run dev`
